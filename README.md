Fit Log is a web-based fitness tracking application designed to help users log, monitor, and manage their daily workouts, fitness routines, and activity progress. Built with a responsive design, it offers a user-friendly interface to set health goals, keep track of daily exercises, and build a consistent workout habit.



#----Technologies Used------
Frontend: HTML5, CSS3, JavaScript (ES6+)
Frameworks: Tailwind CSS / Bootstrap *(Adjust based on your project)*
Icos:FontAwesome / Lucide Icons
Version Control: Git & GitHub


#---Features---#

1. Interactive Workout Logging: Easily log daily workouts, including exercise types, sets, reps, and durations.
2. Activity Dashboard: A clean visual display summarizing daily and weekly fitness activities.
3. Calorie & Duration Tracker: Automatically calculates estimated calories burned and total exercise time.
4. Goal Setting & Progress Monitoring: Set daily/weekly fitness targets and track progress over time.
5. Responsive & Mobile-Friendly Layout: Fully optimized for seamless use on smartphones, tablets, and desktop screens.
